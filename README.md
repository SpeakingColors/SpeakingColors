# Hi, I'm Meow 🐈

I build free, open source music tools, Linux first: hardware controller plugins, creative plugins, synths and a sample manager.

## Projects

**Synths and units**
- [SupurrSaw](https://github.com/SpeakingColors/SupurrrSaw-VST): supersaw, hoover and acid synth
- [HyperSawX](https://github.com/SpeakingColors/super-duper-stuff) (minilogue xd), [hypersaw-xd](https://github.com/SpeakingColors/hypersaw-xd), [sawwiden-xd](https://github.com/SpeakingColors/sawwiden-xd), [hypersaw-drumlogue](https://github.com/SpeakingColors/hypersaw-drumlogue), [MegaSaw XD](https://github.com/SpeakingColors/MegaSaw-XD) (planned)

**Studio tools**
- [Whiskerwave](https://github.com/SpeakingColors/Whiskerwave-vst): wavetable synth with generated waves and a hardware capture tool (planning)
- [Clawpressor](https://github.com/SpeakingColors/Clawpressor-vst): multiband compressor and limiter (planning)
- [CATalog](https://github.com/SpeakingColors/CATalog): sample manager
- [Purrfect Cut](https://github.com/SpeakingColors/purrfect-cut): audio editor
- [cat-ui](https://github.com/SpeakingColors/cat-ui): shared UI

**Creative plugins**
- [AI Purrformer](https://github.com/SpeakingColors/AI-Purrformer): AI singing voice tool (planning)
- [Scaredy Cat](https://github.com/SpeakingColors/scaredy-cat), [Stretch Cat](https://github.com/SpeakingColors/stretch-cat-vst), [Copycat](https://github.com/SpeakingColors/copycat-vst), [Scratch Cat FX](https://github.com/SpeakingColors/scratchcatfx-vst), [Scratch Cat Duo](https://github.com/SpeakingColors/scratchcatduo-vst)

**Hardware controllers (Linux)**
- [WhiskerMix](https://github.com/SpeakingColors/whiskermix), [Peak](https://github.com/SpeakingColors/linux-peak-controller), [UltraNova](https://github.com/SpeakingColors/linux-ultranova-controller), [Cobalt8M](https://github.com/SpeakingColors/Cobalt8M-Controller-VST), [MODX M](https://github.com/SpeakingColors/modxm-controller-vst), [drumlogue](https://github.com/SpeakingColors/drumlogue-linux-controller), [minilogue xd](https://github.com/SpeakingColors/minilogue-xd-controller), [MX400](https://github.com/SpeakingColors/mx400-vst-linux), [M-VAVE FM-1](https://github.com/SpeakingColors/mwave-fm1-linux-vst), [TD-3-MO](https://github.com/SpeakingColors/td3mo-vst), [Pro-1](https://github.com/SpeakingColors/catpro1), [JT-4000](https://github.com/SpeakingColors/jt4000-vst), [PRO VS Mini](https://github.com/SpeakingColors/provsmini-vst)
